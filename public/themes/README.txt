IMAGES DE FOND PAR THÈME — jeu Undercover
=========================================

Depose ici une image de fond par thème. Elle s'affiche sur l'ecran host ET les
telephones pendant la partie, avec un voile sombre par-dessus pour garder le
texte lisible.

Fichiers attendus (nomme-les EXACTEMENT comme ca) :

  marine.jpg   -> mode Classique (mots FR)
  gold.jpg     -> modes Anime melanges / Anime recents
  ring.jpg     -> mode Univers precis

Un fichier absent = pas d'image pour ce mode (seule la couleur de fond s'affiche,
aucune erreur). Formats acceptes : .jpg (conseille), .png, .webp — mais garde le
nom en .jpg OU dis-moi si tu preferes une autre extension et je l'ajuste.

Astuce : prends des images assez sombres / peu chargees au centre, sinon le
texte par-dessus sera moins lisible (le voile aide deja beaucoup).
