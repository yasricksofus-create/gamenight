Sons de CASCADE (séparés de l'Undercover pour ne PAS partager la même musique).

Dépose ici tes fichiers .mp3 (ceux qui manquent restent silencieux) :

MUSIQUES (une seule à la fois, fondu enchaîné) :
  reglages.mp3   -> pendant le vote des règles
  ambiance.mp3   -> pendant la partie (en boucle)
  victoire.mp3   -> quand un joueur gagne

BRUITAGES (joués par-dessus la musique, qui baisse 2s) :
  carte.mp3      -> une carte est posée
  pioche.mp3     -> un joueur pioche
  attaque.mp3    -> un +2 / +4 est joué
  uno.mp3        -> un joueur annonce UNO

Variantes automatiques : ajoute reglages2.mp3, ambiance2.mp3, carte2.mp3 ...
(jusqu'à 8) et le jeu en choisira une au hasard, sans rien changer au code.
